# Origine du projet

Ce repository est une copie de travail dérivée du projet original
**publisher-app**, créé et développé par **Amira Dgham**
(https://github.com/Amira-Dgham/publisher-app).

Cette copie a été créée dans le cadre d'un stage d'été (projet TaskMind),
afin de tester un pipeline d'automatisation agentique (Spec-Driven
Development avec GitHub Spec Kit) sur une base de code réelle existante.

Toute l'implémentation métier originale (backend Spring Boot, frontend
Angular, tests d'automatisation) est le travail d'Amira Dgham.
Les ajouts propres à ce repository (configuration Spec Kit, agents
GitHub Copilot, artefacts de spécification) sont réalisés dans le cadre
de ce stage.
